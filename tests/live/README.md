# فحص المنصة على السيرفر الحقيقي

فحص تلقائي يدخل بحسابات اختبار (`fm.test.*@rakizora.test`) ويجرّب الصلاحيات وأوامر العمل والتواصل مع المدارس، ثم يفتح المنصة وتطبيق الميدان في متصفح بكل حساب.

- كل ما يُنشئه الفحص يكون على «مدرسة اختبار RakizoraFM» (`TEST-RKZ-001`)، وعناوينه تبدأ بـ «[اختبار]».
- أثناء فحص الواجهة تُمنع أي كتابة غير أوامر العمل والتواصل، فلا يُمس ملف المدارس المشترك ولا البلاغات.

## الإعداد (مرة واحدة)

1. **إعدادات البيئة في Claude:**
   - Network access: أضف `hjumfnwabrtexyenshkg.supabase.co` و`cdn.jsdelivr.net` و`cdnjs.cloudflare.com`.
   - متغير `FM_TEST_PASS`: كلمة مرور حسابات الاختبار.
2. **في Supabase:** شغّل `set_password.sql` بنفس كلمة المرور. اكتبها في SQL Editor فقط، ولا ترسلها في المحادثة.
3. **مدرسة الاختبار:** مُسندة للمشرف والمهندس التجريبيين. إن حُذف الإسناد، يعيده حساب المدير التجريبي، أو يعيده المدير من صفحة «التواصل مع المدارس».

## التشغيل (بعد أي إضافة)

اطلب من Claude: «شغّل فحص المنصة الحي»، أو شغّل بنفسك:

```bash
cd tests/live
NODE_USE_ENV_PROXY=1 NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt node api_test.js
NODE_USE_ENV_PROXY=1 NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt node ui_test.js
```

**فحص V179–V187** (الاشتراك والأجزاء، الإشعارات، المستودع والعهد، المستخلصات، مركز التكلفة، أرقام الاستخدام):

```bash
NODE_USE_ENV_PROXY=1 NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt node v180_test.js
```

- يحتاج حساب المدير التجريبي. يتوقف دون أي كتابة إذا لم يُشغَّل `supabase_setup.sql` الجديد (الأقسام 23–28).
- ينشئ حساب `fm.test.storekeeper@rakizora.test` (أمين مستودع، بنفس كلمة المرور) إن لم يوجد. منطقته «test»، فلا يتصرف إلا في مستودع الاختبار.
- كل ما ينشئه اسمه يبدأ بـ «[اختبار]» أو رمزه `TEST-CC`: صنف، مستودع، عقد، مسودة مستخلص، مركز تكلفة.
- يفحص الإشعارات (V187) بجهاز وهمي على `push.invalid` ويحذفه في النهاية.
- لا يعتمد مستخلصاً ولا يصرفه، ويلغي قيد مركز التكلفة الذي يضيفه، فلا تتأثر أرقام مركز التكلفة.
- إذا وُجد ممثل للجهة المالكة، يبقى الصنف التجريبي بانتظار اعتماده، فتُتخطّى فحوص الصرف والعهدة.
- النتائج في `v180_results.json`. بعده شغّل `reset.sql` كالعادة، فهو يحذف بيانات هذا الفحص أيضاً.

- **النتائج:** ✅ ناجح، ❌ فاشل، ⏭️ متخطّى. تُحفظ في `api_results.json` و`ui_results.json`، وصور الشاشات في `out/`.
- **بعد الفحص:** شغّل `reset.sql` في Supabase. يحذف أوامر وسجلات الاختبار فقط، حتى لا تظهر في مؤشراتك، ويُبقي الحسابات. تقييمات المدارس وروابطها (V160) تُحذف تلقائياً مع سجلات التواصل.
- **لحذف الحسابات نهائياً:** شغّل `remove_users.sql`.

## ما لا يغطيه الفحص

- جوال حقيقي: الكاميرا والموقع الفعلي.
- العمل بدون إنترنت على السيرفر الحقيقي.
- الطباعة الفعلية.
- صور تقرير PDF تُفحص روابطها فقط، لأن نافذة التقرير خارج شبكة المتصفح في الاختبار.
