# RakizoraFM V337 — إدارة دورة القوى العاملة

## التحديثات

- لوحة القوى العاملة أصبحت أول صفحة بالقائمة وتعرض ملخصًا حسب المنطقة وجهة العمل، وعدد الأفراد غير المسندين، وعجز العدد المطلوب، والمؤهلات التي تقترب من الانتهاء.
- سجل الفرد يتضمن القسم والتخصص ونوع التعاقد وتاريخ المباشرة وانتهاء العقد.
- خطة شهرية تقارن العدد المطلوب والمعتمد بالقوى النشطة المسجلة حسب المنطقة والفئة والمسمى وجهة العمل.
- إدارة الإجازات تتضمن المدة، الحالة، البديل ومراجعته؛ وتظهر الإجازة المعتمدة في تحذيرات تغطية الفريق اليومية حتى يُسجل البديل حضوره.
- سجلات التدريب والتراخيص والشهادات تعرض المنتهي وما يوشك على الانتهاء.
- الحركات الوظيفية توثق النقل بين المناطق والفرق، وإنهاء التكليف والعودة للعمل، مع السبب وتاريخ السريان وسجل تدقيق.
- استيراد وتصدير CSV يشملان بيانات القسم والتخصص والتعاقد والتواريخ، والاستيراد الجماعي ذري: إذا فشل صف تُلغى العملية كلها.
- تبقى بيانات الحضور والعمل اليومي مرتبطة بأقسام المتابعة الحالية. لا يحول غياب سجل إلى غياب معتمد.

## الترحيل

- لقاعدة موجودة على V336: خذ نسخة احتياطية، ثم شغّل `migration_v337_workforce_management.sql` مرة واحدة، وبعدها حدّث الواجهة.
- التثبيت الجديد: `supabase_setup.sql` يتضمن مخطط V337 كاملاً.
- يحتاج المستخدم صلاحية إدارة القوى العاملة في المنطقة لإضافة الخطة أو اعتماد الإجازة أو تحديث التأهيل والحركات.
- لا تُدخل رقم الهوية أو الراتب أو التشخيص الطبي في السجل التشغيلي. ملاحظة الإجازة مخصصة للتغطية التشغيلية فقط.
- لا توجد بيانات افتراضية أو مستوردة تلقائيًا؛ عبّئ الخطة والبيانات الحقيقية بعد الترحيل.

## ملاحظات تشغيلية

- مؤشرات الخطة تعتمد على تطابق المنطقة والفئة والمسمى وجهة العمل في سجل الأفراد النشطين؛ راجع بيانات التوزيع قبل اعتماد العجز.
- البديل لا يُحسب حضورًا إلا بعد تسجيل حضوره واعتماد السجل اليومي.
- ملف CSV يستخدم أعمدة إنجليزية ثابتة كي يبقى متوافقًا مع Excel والاستيراد.
