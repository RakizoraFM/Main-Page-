# RakizoraFM — تطوير إدارة القوى العاملة

## ما أُضيف في هذا التغيير

- تظهر صفحة القوى العاملة أولاً في قائمة التنقل.
- تبدأ صفحة الإدارة بلوحة ملخص تشمل الأفراد النشطين، كادر الشركة، عمالة مقاولي الباطن، الأفراد غير المسندين إلى فريق، الفرق، والمباني المسندة.
- تعرض اللوحة توزيع القوى العاملة حسب المنطقة وأكبر جهات العمل.
- تضيف اختصارات للحضور والتوفر، وإدارة الفرق، وتغطية المباني.
- تضيف تصديراً إلى CSV يفتح في Excel، مع دعم البحث قبل التصدير.
- لا تحتاج هذه الإضافات إلى ترحيل قاعدة بيانات، ولا تضيف حقولاً شخصية جديدة. الأعداد المعروضة أعداد السجل النشط، ولا تعني الحضور الفعلي.

## التوسع المقترح للصفحة

يقسم سجل القوى العاملة إلى أقسام واضحة:

1. **لوحة القوى العاملة:** الاحتياج المعتمد مقابل المتوفر، الشواغر، والتوزيع حسب المنطقة والإدارة والمقاول.
2. **سجل الأفراد:** كادر الشركة، فرق الصيانة، الخدمات الخفيفة، والطقم الإداري والمساند؛ مع المسميات والتخصصات والمدير والفريق ومواقع التكليف.
3. **الإدارات والفرق:** الهيكل التنظيمي، قائد الفريق، العدد المخطط والفعلي، ونطاق التغطية.
4. **التوزيع على المباني:** المواقع المسندة، والخدمة، والفريق، ومؤشر النقص لكل نطاق.
5. **الحضور والتوفر:** الغياب والإجازات والبدلاء والتغطية اليومية.
6. **الأداء وحمل العمل:** مؤشرات ملائمة لكل دور، مرتبطة بأوامر العمل والبلاغات والزيارات وجودة الإغلاق.
7. **التأهيل والوثائق:** الدورات والكفاءات والتراخيص وتواريخ انتهائها.
8. **الحركة الوظيفية:** تعيين، نقل فريق أو منطقة، إيقاف، وإنهاء تكليف مع سجل مراجعة.
9. **تقارير القوى العاملة:** التصدير حسب المنطقة أو الإدارة أو المقاول والفترة.

## ضوابط مقترحة

- قياس الأداء حسب الدور ونوع المهمة، وعدم ترتيب الموظفين بمؤشر موحد لا يراعي اختلاف الأحمال.
- إظهار الفرق بين «غير مسند» و«لا يوجد حضور مسجل» و«غائب معتمد».
- صلاحيات منفصلة لبيانات الاتصال، الحضور، الوثائق، والمعلومات الإدارية؛ ولا تُضاف أرقام الهوية أو الرواتب إلى السجل التشغيلي العام.
- حفظ سجل تدقيق لكل تعديل على التعيين والتوزيع والحالة.

التوسع إلى الحضور والوثائق والحركة الوظيفية يحتاج تحديد حقول وصلاحيات ودورة اعتماد قبل إضافة جداول جديدة أو ترحيل قاعدة البيانات.
