# V332 — روابط المنصات من الواجهة

افتح مركز التكامل من القائمة. أضف اسم المنصة ومعرّف المصدر الثابت ونوع البيانات ورابط فتحها. أضف رابط البيانات اختيارياً ثم احفظ. يمكنك إضافة أكثر من منصة وتعديل الروابط أو حذف الإعداد في أي وقت. تغيير الرابط لا يغيّر معرّف المصدر.

فتح المنصة يعمل برابط HTTPS تختاره. جلب البيانات يحتاج CSV أو مصفوفة JSON بنفس حقول القالب، وأن يسمح المصدر بـ CORS. الجلب GET للقراءة فقط، دون كوكيز أو بيانات دخول ودون اتباع إعادة توجيه؛ حد 5 MiB ومهلة 20 ثانية. البيانات تُعرض في المعاينة قبل اعتمادها في مساحة المراجعة المحلية فقط.

هذه ليست مزامنة تشغيلية تلقائية. لا تحويل حقول ولا مصادقة API سرية ولا كتابة في النظام الخارجي أو قاعدة التشغيل. رابط الصفحة الرئيسية يفتح المنصة ولا يستخرج بياناتها. حفظ الإعدادات على المتصفح فقط؛ نسخة الجلسة تحفظ البيانات ولا تتضمن إعدادات الروابط. لا تدخل أسراراً في الروابط.

نجح فحص JavaScript واختبار إعدادات الروابط في بيئة معزولة: الإضافة والتعديل والحفظ والفتح والجلب والمعاينة ورفض الروابط غير الآمنة وفشل CORS. نجحت اختبارات مطابقة V331. لم يختبر اتصال فعلي بمنصة مستخدم أو واجهة متصفح حقيقية.
