# ERP002 — واجهة إدارة المشروعات

> **استُبدلت في V352:** صفحة «🏗️ المشروعات» أصبحت طبقة `fm-v352-erp-projects` داخل index.html (رقم إصدار، دليل المنصة، مجموعة «النظام»، ترجمة، ونشر Cloudflare). حُذف `erp-projects.js` / `erp-projects.css` واختباراهما لأن الملفين لم يكونا ضمن `tools/cf_build.sh` وكانت الصفحة ستظهر مرتين. الوصف أدناه للتاريخ فقط.

تضيف هذه الدفعة زر «إدارة المشروعات» إلى القائمة الجانبية لمدير النظام الفعّال داخل الشركة الحالية. تستخدم جلسة FMCloud وعميل الشركة الحالي، وتستدعي دوال ERP001 دون الكتابة المباشرة إلى الجداول.

## الوظائف

- إنشاء مشروع بكود واسم ورمز منطقة.
- اختيار المشروع وعرض أعضائه وأعداد أوامر العمل المتاحة.
- إضافة أو إلغاء عضوية مستخدم مع تسجيل السبب.
- البحث بالكود أو عنوان أمر العمل، وعرض غير المنسوب أو المشروع المحدد أو كل الأوامر المتاحة.
- تحميل السجلات على دفعات 500، وعرض النتائج على دفعات 50.
- ربط أمر العمل أو تصحيح مشروعه مع السبب ورقم المراجعة؛ رفض اختلاف المنطقة في الواجهة والقاعدة، وإعادة القراءة عند تعارض المراجعة دون تكرار الحفظ تلقائياً.

## المتطلبات والحدود

يجب تطبيق `supabase/migrations/202611170001_erp_project_foundation.sql` على قاعدة اختبار الشركة أولاً. تعرض الصفحة رسالة واضحة عند غياب الجداول. لم يطبق هذا العمل أي SQL على الإنتاج، ولا ينسب الأوامر القديمة تلقائياً. عضوية المشروع لا تحل محل صلاحيات التشغيل الحالية ولا تفرض عزل المشروع على المسارات القديمة. أرقام الواجهة محسوبة من السجلات المتاحة للجلسة الحالية وليست تقريراً مالياً.

الملفان `erp-projects.js` و`erp-projects.css` منفصلان عن طبقات الشيفرة السابقة، وتحمل الصفحة الرئيسية كليهما في نهايتها. لا توجد مكتبات تشغيل إضافية.

## التحقق

- `node --check erp-projects.js` نجح.
- `node tests/integration/html-syntax.cjs` نجح: 304 نصوص مضمنة.
- `node tests/integration/erp001.mjs` نجح: 12 سيناريو قاعدة بيانات مع المخطط الكامل في PGlite.
- `node tests/integration/erp002-dom.cjs` نجح باستخدام jsdom: تحميل 505 سجلات، بحث، عرض نص آمن، إسناد ورقم مراجعة، تعارض تحديث، إضافة وإلغاء عضوية، اختلاف منطقة، إنشاء مشروع، غياب الترحيل وصلاحية المدير. يعتمد الاختبار على تجهيز البيانات المشترك داخل `erp002-browser.cjs`.
- `node tests/integration/erp002-browser.cjs` موجود للفحص البصري والسلوكي عند توفر Chromium قابل للتشغيل. تعطل قبل فتح الصفحة في بيئة التنفيذ بسبب منع socket في Chromium؛ لذلك لا يُعتبر فحص سطح المكتب أو الموبايل ناجحاً بعد.

الاعتماديات للاختبارات فقط: PGlite وjsdom وPlaywright في مجلد خارجي؛ لا ترفع node_modules. لا تغطي الاختبارات الاتصال بقاعدة Supabase الحية أو تسجيل الدخول الحقيقي أو المظهر داخل المنصة الكاملة. يجب تجربة ذلك على بيئة اختبار قبل إطلاق الواجهة للمستخدمين.
