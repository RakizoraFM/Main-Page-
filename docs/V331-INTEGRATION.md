# V331 — مركز مراجعة التكامل

افتح index.html ثم «مركز التكامل · مراجعة الملفات»، أو افتح integrations.html مباشرة.

## المنفذ
- رفع CSV أو مصفوفة JSON للبلاغات ولقطات الأرصدة وحركات المخزون.
- المطابقة على المصدر + النوع + الرقم الخارجي؛ التكرار داخل الملف مستبعد بالكامل.
- إعادة الاستيراد لا تضيف السجل مرتين. تحديث أحدث يستبدل النسخة السابقة؛ الأقدم والتعارض بنفس التوقيت مستبعدان.
- معاينة ثم اعتماد محلي، تقرير فحص، تنزيل واستعادة نسخة جلسة.
- فصل لقطات الأرصدة عن الحركات. صافي تكلفة الحركات لكل مصدر وحده، مع استبعاد الملغى وطرح الإرجاع.
- حد الملف 5 MiB وحد الدفعة 10000 سجل. الجداول تعرض أول 500 صف والتقرير كامل.

## حدود هذه المرحلة
هذه مساحة مراجعة مستقلة في ذاكرة الصفحة؛ لا تحفظ تلقائياً ولا تكتب في قاعدة التشغيل. تنزيل نسخة الجلسة ضروري قبل الإغلاق. لا مفاتيح سرية ولا اتصال API ولا مزامنة بين الأجهزة. ربط رموز المباني والبلاغات بالسجلات الفعلية لم ينفذ بعد. السجل المعروض سجل جلسة محلي وليس سجل تدقيق خادمي معتمداً.

يجب أن يثبت اسم المصدر عبر الملفات. snapshot external_id يحدد بند الرصيد في مستودعه بشكل فريد، مثل warehouse:sku. movement external_id هو رقم الحركة الأصلي؛ الإلغاء يحدّث نفس الرقم بتاريخ أحدث. العودة حركة مستقلة جديدة.

## المطلوب للربط المباشر
اسم ورابط منصة البلاغات ومنصة المستودع، وثائق API/Webhooks أو عينات تصدير فعلية منزوعة البيانات الحساسة، واتجاه التبادل ومالك الحالة والتكلفة. بعد ذلك تنفذ موصلات خادمية مع صلاحيات ونطاق شركة وإعادة محاولة ومصالحة وسجل أحداث. لا تضع أسرار المنصات في HTML.

## التحقق
نجح اختبار core: الإضافة، تحديث أحدث، إعادة الاستيراد، التكرار، التعارض، التحديث الأقدم، عزل المصادر، CSV متعدد الأسطر، الأرقام النصية، إلغاء الصرف، الإرجاع والقيم الرقمية غير الصحيحة.
نجح فحص صياغة JavaScript للملفين الجديدين. تعذر تشغيل اختبار المتصفح لأن البيئة منعت socket الخاص بتشغيل Chromium؛ لذلك لم يتحقق بصرياً من الصفحة أو القائمة داخل التطبيق. اختبارات SQL الخاصة بالمستخلصات لم تعد لعدم تعديل SQL أو حسابات الفوترة.

لا نشر إنتاجي ولا تنفيذ SQL في هذا الإصدار.
